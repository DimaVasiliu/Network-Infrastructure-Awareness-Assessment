# Reference materials (NOT committed)

This directory is intentionally empty in the repository. Its parent `.gitignore`
excludes the contents.

The official ECS Network Infrastructure Awareness assessment guide PDF
(© The JIB) is used only as a topic map for original question writing. It must
**not** be committed to source control, because:

1. It is copyrighted material; redistribution via the repo is infringing.
2. A public repo with that PDF inside is a takedown candidate.

The PDF currently lives at:

```
~/Desktop/Network Infrastructure Awareness Assessment/ECS-Network-Infrastructure-Awareness-guide.pdf
```

That path is **outside** the git repo and is therefore safe.

If you need to read the PDF while working on the question bank, open it from
that location. Do not copy it back into this folder.

See `docs/CONTENT_COMPLIANCE.md` for the rules around what may and may not be
copied from the PDF into the app.
