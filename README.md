# Network Infrastructure Awareness Trainer

Independent study app for the UK Network Infrastructure Awareness Assessment.

## Repository layout

- `app/` - Expo React Native application.
- `docs/` - planning and project documentation.
- `reference/` - source reference material used only for research and topic mapping.

## Current phase

Phase 1: app skeleton and original question-bank structure.

Do not copy official assessment questions into the app. The reference PDF is only a topic map for writing original study questions.

## Local development

```bash
cd app
npm install
npx expo start -c
```
