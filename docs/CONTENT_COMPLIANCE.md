# Content Compliance Notes

The official assessment guide is copyrighted by ECS / The JIB. The app question bank must not copy the guide's wording, question order, explanations, or close paraphrases.

Allowed source use:

- Use the guide as a topic map.
- Use uncopyrightable facts, codes, standards references, and numerical values.
- Write original scenarios, answer choices, and explanations.
